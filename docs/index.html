03

FAQ

Woher kommen die Preisfehler?

Das Radar liest öffentliche RSS-Feeds von Deal-Communities (u. a. die Gruppe „Preisfehler“ bei mydealz) und erkennt Beiträge mit Begriffen wie „Preisfehler“ oder „Fehlerpreis“. Amazon selbst wird nicht ausgelesen.

Wie schnell bin ich benachrichtigt?

GitHub führt den Check etwa alle 5 Minuten aus (in Stoßzeiten können es auch 10–15 sein). Dazu kommt die Zeit, bis jemand den Fehler in der Community meldet. Für echte Echtzeit bräuchte es einen eigenen Server.

Bekomme ich die Ware garantiert?

Nein. Händler dürfen Bestellungen zu Preisfehlern stornieren. Bestelle nur, was du auch zum Normalpreis akzeptieren würdest, und plane die Stornierung ein.

Kostet das etwas?

Nein. GitHub Pages, GitHub Actions (öffentliches Repo) und ntfy sind kostenlos.

Kann ich auch andere Shops bekommen?

Ja: Schalte oben auf „Alle Shops“ oder setze in tracker/config.json "notify_only_amazon": false, dann pusht das Radar jeden Shop.
